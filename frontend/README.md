# Frontend (React + Tailwind)

This frontend is a lightweight React scaffold for the e-commerce app. It uses React Router and Axios to communicate with the backend API.

To run:

1. Install deps (from `frontend/`):

```cmd
npm install
```

2. Start dev server:

```cmd
npm run start
```

Note: Tailwind setup is minimal here. You can integrate Tailwind by following the official Tailwind + Vite guide.
